# Organize Your Workspace

## Keep Important Threads Pinned

Pinned threads stay together above the active thread list on web, desktop, and mobile.

- On web or desktop, right-click a thread and choose **Pin thread**. Use **Unpin thread** to return it to the normal list.
- On mobile, open the thread's action menu and choose **Pin** or **Unpin**.
- Settling a pinned thread marks it done and removes its pin.
- Snoozing a pinned thread hides it until the wake time. It returns to the pinned section when it wakes.

## Group Related Projects

Project grouping combines workspaces that belong to the same repository. On web or desktop, open
**Settings → General** and turn **Project grouping** on or off. On mobile, open **Settings → Project
Grouping** to group by repository, group by repository path, or keep every workspace separate.

## Choose Fonts and Text Sizes

Open **Settings → Appearance** to choose fonts and sizes for the interface, prompt editor, code and
diffs, and terminal. Each surface can keep its default or use its own setting.
